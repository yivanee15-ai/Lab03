# 徐宗國〈紮根理論研究法：淵源、原則、技術與涵義〉中文統整

*《質性研究》第三章，頁 47–73（原文刊載於《香港社會科學學報》第四期，1994 秋季）*

## 一、論文要解決什麼問題
- **背景**：當時美國社會學有兩種極端：只有宏大概念、缺乏經驗資料的「鉅型理論」，以及只做變數分析的「抽象經驗論」。兩者造成理論與資料脫節。紮根理論想回應 Blumer 對社會學的批評，在「社會學需要建立理論」的目標下，主張質化研究也應著重資料分析與建立理論。
- **本文目的**：說明紮根法的淵源、原則與技術，澄清一些誤解（例如「它只有歸納、沒有演繹」），並討論它對社會科學，尤其是婦女研究的涵義。
- **主要依據**：Strauss (1987)、Strauss & Corbin (1990)，並用作者自己研究補習班、女醫師、女作家的例子說明。

## 二、淵源（四個學術基礎）
1. **科學的邏輯**
   - 紮根法被認為是質化方法中最科學的一種：遵循歸納與演繹並用、比較、假設驗證、理論建立等原則。
   - 它同時保持彈性：樣本數多少、如何理論性抽樣、何時停止，都靠研究者的理論觸覺判斷。
   - 例子：訪問女醫師時，妻子與丈夫對轉換工作原因的說法不同，不必視為其中一方不誠實，而可用來思考雙方為何有這樣的觀感。
   - 對誤解的澄清：Glaser & Strauss (1967) 讓人以為紮根法只有歸納。其實 Strauss (1987, 1990) 強調它是一面蒐集資料、一面檢驗的連續循環，程序裡已有檢驗手續。
   - **想像的比較**：不必有第二筆資料，研究者在概念上就能拿不同對象來比較以刺激思考。例如把補習班與囚牢的空間設計比較，得出「空間剝奪」的概念。
2. **實用主義 (pragmatism)**
   - 解決問題時先分解再綜合，所以有「開放式登錄」（分解）與寫備忘錄（綜合）。
   - 研究題目來自日常生活，成果也回歸日常生活。
   - 理論永遠是暫時的，是工具，會因新資料而修正，沒有神聖性。
   - 教學上，學生在小組討論中學習登錄技巧。
3. **象徵互動論 (symbolic interactionism)**
   - 核心觀點：行動者有自我，會賦予事物意義並據以行動；意義來自互動過程與社會；社會現象不斷萌生。
   - 影響紮根法：建理論是一個過程，理論是暫時的；變數之間彼此影響，不看單一因果；理論必須從行動者的詮釋出發；要捕捉社會過程。
4. **工作社會學 (sociology of work)**
   - Strauss 承襲芝加哥社會學研究工作、職業與組織的傳統，把建構理論與教學也視為一種「工作」。
   - 研究者的個人經驗、背景、訓練，在日常生活中培養出對研究題目的「觸覺」，使研究與生活相結合。

## 三、原則（三種思考方式）
1. **科學的邏輯**
   - 利用理論觸覺，不斷比較資料，找出相同且重要的特質，給它一個名字，稱為**範疇**，例如「空間剝奪」。
   - 範疇是暫時的，要靠之後更多案例支持。
   - 比較不同補習班、不同月份，可得出假設（例如空間剝奪與消費者的年齡、協商力有關），再以**理論性抽樣**回頭蒐集資料。
   - 當某概念反覆出現，不再有新資料時，就達到**理論性飽和**，可停止蒐集。
   - 若遇到不符的**否定例子**，不必推翻理論，而是用來修飾並增加變異性。
   - 歸納、演繹與假設驗證三者不斷循環。
2. **登錄典範 (coding paradigm)**
   - 思考任一現象時，從四方面切入：事件發生的**情況**、**結果**、**處理措施**、**過程**。
   - 用來比較時，能使不同案例的特徵明顯化，並提供假設。
   - 例子：研究女作家時，比較有／無子女、有／無傭人幫忙，看家庭責任對寫作的影響。
   - 因此理論性抽樣的對象，是**不同情況下的案例**，而非不同特徵的人口。
3. **互動地思考 (think interactionally)**
   - 單位之間的互動：把分析層次（例如工作）放在較大的環境（組織、行業、社區、社會）中思考，連結微觀與宏觀。
   - 過程式思考：把現象視為發展中、變遷中 (becoming) 的，注意不同時間點的變化。

## 四、技術（分解與綜合的來回）
1. **開放式登錄 (open coding)**
   - 研究初期，逐字逐句分解文字資料，找出重要的社會現象並命名為範疇。
   - 好處：被迫慢下來思考；用資料而非既有文獻產生想像，更有創意；早期做得愈完備，愈能減少日後浪費資源。
2. **命名**
   - 來源有二：被訪者的用語（**in vivo concepts**，貼近當事人眼光），或研究者自創較抽象的詞。
   - 每個範疇有**面向**與**特徵**，使理論豐厚。
   - 經過不斷比較，抽象度高的範疇成為**核心範疇**，是理論的主題。
3. **撰寫備忘錄**
   - 登錄是分解，備忘錄則是開始綜合。內容包括對資料的理論性解釋、思路與研究設計。
   - 寫作時被迫理論性思考，並在歸納（資料到文字）與演繹（文字回到觀察）之間來回。
   - 寫作要點：一份備忘錄只談一個主題，並標註日期以便追溯思考歷程。
4. **排列備忘錄**
   - 依主題排列備忘錄，本身就是一種理論性的詮釋與綜合。
   - 排列的秩序成為研究報告的大綱，並提供有說服力的描述與引用句。

## 五、涵義與結論
- 紮根法的特色：既嚴謹、遵守科學原則，又有方法上的彈性；兼顧理論的普遍性 (nomothetic) 與個案的具體性 (idiographic)；其程序使質化研究的共同特色更為明顯。
- **對「本土化」的啟示**
  - 理論由日常經驗建構，並以當事人的語言（in vivo 範疇）表達。
  - 訓練人比改良方法更重要：研究者靠理論觸覺、邏輯思考、人生經驗做判斷。
  - 文獻被視為資料的一種，要經過驗證才成為理論的一部分，不被神聖化，這種「草根性」有助社會學的中國化。
- **對婦女研究的啟示**
  - 婦女經驗常具隱約、非意識到、私下、非正式的性質（如照顧嬰兒、協調工作與家庭），量化不易處理，紮根法能由資料出發建立概念，並擺脫既有文獻對女性聲音的忽略。
  - 婦女研究有改變現狀的行動目標；紮根法容許研究者運用個人經驗、情緒與動機，與被研究者互動、甚至促成雙方改變。
  - 婦女研究缺乏獨特的資料蒐集與分析思考方式，紮根法可作為方法之一。
- **對方法論爭議的啟示**
  - 國內社會學研究多落入鉅型理論或抽象經驗論；紮根法由微觀出發，逐步連結宏觀，提供另一種選擇。
  - 學習 Strauss：從實質研究中發展方法，而非先從方法著手；以研究興趣發展出實質理論，再抽繹成形式理論。
  - 教學重視想像力與理論觸覺的培養；Hughes 主張質化方法的使用可成為「社會學的社會學」練習。
  - 質化與量化各自有不同的基本假設與判斷標準，不應把量化標準不加修正地套用到質化研究上；雙方都應了解對方，減少無謂的批評。

## 專有名詞解釋

### 研究取向
| 名詞 | 解釋 |
|---|---|
| 質性研究 (qualitative research) | 以文字、訪談、觀察等資料，深入了解社會現象的意義與過程的研究，與以數字統計為主的量化研究相對。 |
| 紮根理論 (grounded theory) | 理論直接從系統性蒐集的資料中「長」出來，而非先有理論再去驗證；強調資料蒐集、分析與建理論同時並進。 |
| 鉅型理論 (grand theory) | 抽象、宏大、缺乏經驗資料支持的社會理論，源自 C. W. Mills 的批評。 |
| 抽象經驗論 (abstracted empiricism) | 只做變數間的統計關係，忽略整體社會情境，過度簡化社會實體。 |
| 歸納 / 演繹 | 歸納是由資料概括出概念與理論，演繹是由理論推出假設再用資料檢驗。紮根法兩者交替使用。 |
| 普遍性 (nomothetic) / 個案具體性 (idiographic) | 前者追求一般性的規律，後者描述個別案例的特殊細節。 |

### 學術淵源
| 名詞 | 解釋 |
|---|---|
| 實用主義 (pragmatism) | 重視理論的實用性，理論是解決問題的暫時性工具，會依經驗修正。 |
| 芝加哥學派 | 美國早期的社會學學派，重視田野調查與日常生活。 |
| 象徵互動論 (symbolic interactionism) | 認為人透過符號與他人互動，賦予事物意義並據以行動，社會現象因此不斷變動。 |
| 工作社會學 (sociology of work) | 研究工作、職業與組織的社會學分支；Strauss 把研究本身也視為一種工作。 |
| 協商秩序 (negotiated order) | Strauss 的觀點：社會秩序是各方不斷協商而來的，並非固定不變。 |

### 思考原則
| 名詞 | 解釋 |
|---|---|
| 理論性觸覺 (theoretical sensitivity) | 研究者憑理論訓練、實務經驗與個人背景，對資料中有理論意義的現象特別敏感的能力。 |
| 比較的原則 | 不斷拿不同案例、情境互相比較，找出相同與相異之處，提取概念。 |
| 想像的比較 | 沒有實際資料也能在概念上比較（例如補習班與囚牢），用來刺激思考與提出假設。 |
| 理論性抽樣 (theoretical sampling) | 依據理論發展的需要，決定下一步蒐集什麼資料、找什麼對象，而非隨機或按人口特徵抽樣。 |
| 理論性飽和 (theoretical saturation) | 對某概念再蒐集資料也不會有新發現時，表示已飽和，可以停止。 |
| 否定例子 (negative case) | 與目前形成的趨勢不符的案例，用來修飾理論、增加變異性。 |
| 修飾 (qualification) | 加入條件或限制，說明理論在哪些情況下成立、哪些情況下不同。 |
| 登錄典範 (coding paradigm) | 思考現象的四個角度：情況、結果、處理措施、過程。 |
| 互動地思考 (think interactionally) | 同時考慮單位間的互動（微觀與宏觀層次）以及隨時間發展的過程。 |
| 基本社會過程 (basic social processes) | 內容不同的現象中，卻共通的基本社會歷程。 |

### 資料分析技術
| 名詞 | 解釋 |
|---|---|
| 登錄 (coding) | 把原始資料轉換成概念的過程。 |
| 開放式登錄 (open coding) | 研究早期逐字逐句分解資料，找出並命名重要現象。 |
| 分解 (break down) / 綜合 (put together) | 紮根法分析的兩個方向：把資料拆開，再把概念組合成理論。 |
| 範疇 (category) | 研究者給資料中某類社會現象取的名字，如「空間剝奪」，是抽象的概念單位。 |
| in vivo concepts | 直接取自被訪者口中的詞彙作為概念，保留當事人的眼光。 |
| 面向 (dimensions) / 特徵 (properties) | 範疇的組成：特徵是範疇的屬性，面向是這些屬性變化的範圍或層面。 |
| 核心範疇 (core category) | 抽象度最高、能涵蓋其他範疇的概念，是整個理論的主題。 |
| 備忘錄 (memo) | 研究者寫下對資料的理論性解釋、思路與設計的記錄，是分析與綜合的主要工具。 |
| 實質理論 (substantive theory) / 形式理論 (formal theory) | 前者針對某類具體現象（如醫院病人的死亡），後者抽取其共同形式，抽象層次更高。 |

### 其他
| 名詞 | 解釋 |
|---|---|
| 本土化 | 讓研究與理論根植於本地的日常經驗與語言，而非照搬外國理論。 |
| 社會學的社會學 (sociology of sociology) | 把研究過程本身當作社會行動來分析，反省研究者的處境與遭遇。 |
| 婦女研究 (women's studies) | 以女性經驗與立場為中心、帶有改變現狀目標的研究領域。 |
