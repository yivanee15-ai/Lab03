# 高淑清〈現象學方法及其在教育研究上的應用〉中文統整

*《質的研究方法》，頁 93–129*

## 一、論文概述
- **目的**：介紹現象學方法的定義、構成要素、理論基礎與實施步驟，並以實例說明，再探討它在教育研究上的應用。
- **核心立場**：現象學既是哲學也是方法。研究者在沒有預設期望的前提下，用現象學描述的方法系統性地了解生活經驗，讓經驗盡可能以整體呈現其本質。
- **實施主軸**：以「整體－部分－整體」的循環架構為主，輔以還原、描述與尋求本質。
- **啟示**：胡塞爾對研究對象採取極高度的開放與尊重，這種公平、無我、廣納對象的態度，對教育專業人員的研究與實務都有啟示。

## 二、現象學方法的定義與特點

### 1. 定義
- **現象學 (phenomenology)**：探究現象的哲學，由胡塞爾 (Husserl, 1859–1938) 領導。他認為知識來自檢視日常生活經驗，存有只在意識層面呈現，且與意義密不可分。
- **現象學的角色**：澄清生活世界的本質結構，透過意識活動了解世界如何被經驗。
- **現象學方法**：在不預設立場的前提下，用現象學描述，了解呈現在意識層面的生活經驗。過程包括不斷質問、反思、聚焦與直覺，讓經驗以整體的天性呈現其本質。
- **Van Manen**：現象學方法是一種動力交互作用，透過反覆修正文字描述與重寫，把現象陳述出來，也等於重新學習如何看這個世界。

### 2. 五大特點
| 特點 | 內容 |
|---|---|
| **開放性 (openness)** | 研究者對現象抱持好奇與慾望，不預設期待，讓現象展現它本來的面貌。Dahlberg & Drew 提出：開放心胸（聆聽不評判、適度自我表露但不引導）、開放心智（無目標導向地接收訊息）、前置了解與反思（覺知自己先前的了解）。 |
| **立即性 (immediacy)** | 研究者緊密吸引受訪者描述生活經驗，建立信任與親密感，並即時回饋、澄清。但也要保持距離與反思能力，以維持中立。受訪者過度自我揭露時，訪談結束後需有後續支持。 |
| **獨特性 (uniqueness)** | 重視每位參與者獨特的觀點，不做控制、推論或類化。但現象的本質同時展現人類經驗的共通性（同質性 sameness），獨特性與同質性並存。 |
| **意義性 / 意向性 (meaning / intentionality)** | 現象學探求事實背後隱含的意義。意義分三層（Habermas）：事實性、共通性、互為主體性。意向性指意識總是朝向某個對象，現象學描述的就是這種意向經驗。 |
| **互為主體性 (intersubjectivity)** | 研究者不再是主導者，而是與參與者平等合作，視參與者為共同研究者 (co-researcher)，建立彼此尊重與了解的關係。 |

## 三、理論基礎
1. **生活世界 (lifeworld)**
   - 胡塞爾用來描述被直接經驗到的世界，包括日常接觸的人、事、物。
   - 科學世界是經過理智高度抽象化的世界，離主體較遠；科學的真理仍須追溯到生活世界的直觀經驗，所以生活世界是科學的基礎。
   - 生活世界有三種用法：狹義（日常被感知的世界）、特殊世界（不同職業興趣形成的各自世界）、廣義（統一各特殊世界、有基本相同感性經驗的世界）。這成為人類互相理解的橋樑。
2. **現象學的還原 (reduction)／存而不論**
   - 從自然態度轉為先驗的現象世界。日常生活中人們視萬物為理所當然，還原則是把它們掛起來。
   - 關鍵是**懸置 (bracketing)**：把先前知識、假設與信念放進括號，中止判斷，從事物直接給予的內容出發。
   - 關心的是事物「怎麼」對意識顯現，而不是「是什麼」。
   - 要自我約束：不任意對意識之外的事物斷言，也不任意否定。
3. **現象學的描述法 (phenomenological description)**
   - 現象學是描述性的科學，以具體描述取代抽象論證。
   - 不對現象做理念化，也不挖掘背後的深層架構，而是忠實於事物顯現的方式。
   - 研究者可先有粗略輪廓，再在過程中修正。
   - 例子：研究夫妻家庭決策時，先懸置既有知識，再從權力抗爭、性別意識、溝通態度、親密關係等面向抽離出本質。

## 四、實施策略

### 1. 收集資料
- 首重研究者的開放性與研究者–參與者的關係；方法有彈性，要視研究問題、情境脈絡與研究者創造性而定。
- 常用：反觀訪談、觀察、書面敘述、繪畫，以**深度訪談 (in-depth interview)** 最常見。

### 2. 分析資料
- **整體–部分–整體 (whole-parts-whole) 的循環**
  - 先整體閱讀文本，獲得整體感。
  - 再分辨並萃取「部分」（類別與主題），暫時解構情境脈絡。
  - 最後回到整體，擴展意義的了解。
  - 這與 Gadamer 的「了解」一致：了解整體要靠細節，了解細節要靠整體，來回往返。
- **Giorgi 的哲學分析三步驟**：
  1. 具體描述他人在自然態度下的生活經驗。
  2. 確保還原的態度（放置先前知識、以受訪者的角度描述，不加道德判斷）。
  3. 尋求科學性的本質，而非單純的哲學性本質。
- **作者提出的五個具體步驟**：
  1. 收集文本資料（訪談轉成逐字稿）。
  2. 閱讀與再閱讀文本，掌握整體並加註解。
  3. 分類成個別主題（意義單元）。
  4. 重新組織並萃取共同主題（群聚相關意義單元，像把原始材料「煮熟」）。
  5. 統整並陳述現象的本質，並不斷回頭檢視共同主題是否回答研究問題。

## 五、在教育研究上的應用

### 長處
1. 符合教育研究的科學化要求：系統性、明確性、自我批判性、互為主體性。
2. 探索學習經驗的本質，而非只看結果或頻率。
3. 懸置與存而不論有助教育者反省偏見，開放傾聽。
4. 描述法普遍適用，可持續揭發更深入的教育問題。
5. 探索生活世界的真正聲音，增進溝通與互相了解。
6. 深思熟慮 (thoughtfulness)，細膩關懷研究對象。
7. 關心生活本質與意義，有助落實關懷的人本教育。

### 限制
- 並非所有研究問題都適用現象學。
- 現象學不是實證分析科學，不能類化，也不能比較哪個教學法較好。
- 不能用來解決問題，它的問題常是意義性的；但深入了解意義後，個人可能獲得洞察而改善關係。
- 純粹描述而不加解釋很難：描述常夾帶解釋成分（Sartre 的害羞例子：害羞者的意思其實是覺得自己的身體是為他人而存在）。
- 研究生常見誤解：以為質性研究不需要費力分析、需要建立假設，或太擔心信度、效度。

## 六、實例：McClelland (1995)〈孩子上幼稚園：母親經驗的現象學研究〉
- **研究問題**：What is it like to send a child to kindergarten?（強調經驗本質，不問「如何」經歷）。
- **來源**：從研究者個人身為母親的經驗與興趣出發。
- **參與者**：9 位歐裔美籍母親，中輟後在成人補校就讀，有些面臨貧窮、童年受虐、毒癮等困境。
- **場域**：以受訪者感到自在、安全的地方為主（成人補校、家中、診所等）。
- **訪談**：以對話式訪談進行，先暖身、談自己的童年上學，再自然引到孩子上幼稚園；以親切的方式、具體事件開頭，避免大而空泛的問題；全程錄音並完整謄寫。
- **文本分析**：反覆閱讀逐字稿，萃取出母親經驗的主題，必要時回去與受訪者確認。
- **四個共同主題**：
  1. **生命中的改變**：生活步調、時間與情緒的調適。
  2. **憂心煩惱**：擔心孩子的安全、被欺負、被孤立等。
  3. **放手**：學習讓孩子成為獨立個體，也是母親自身的解放。
  4. **混雜的情感**：調適、恐懼、失落、悲傷、快樂、驕傲與希望交織。

## 七、結論
- 現象學強調開放性、追根究柢、探索生活意義與經驗本質、聆聽生活世界的內在聲音，並追求科學性的知識，對教育研究提供了啟示。
- 雖有限制，但培養教育學的能力（pedagogical competence）需要開放、同理、關懷、敏銳的覺察，去接觸受教者的經驗世界。

## 專有名詞解釋

### 哲學基礎
| 名詞 | 解釋 |
|---|---|
| 現象學 (phenomenology) | 探究「現象」如何在意識中顯現的哲學，由胡塞爾創立，也發展成一種研究方法。 |
| 現象 (phenomenon) | 事物對意識所呈現的樣子，而不是事物本身的客觀屬性。 |
| 生活世界 (lifeworld) | 日常生活中直接被經驗到的世界，是科學世界的基礎，也是人類互相理解的共同根基。 |
| 科學世界 | 經過理智活動高度抽象化的理論世界，離直接經驗較遠。 |
| 自然態度 (natural attitude) | 日常生活中視萬物為理所當然、不加懷疑的態度。 |
| 先驗主體 | 回到個人純粹的自我思考與本質結構的「我」，是還原的目標。 |
| 現象學的還原 (reduction) | 從自然態度轉為現象學態度，把理所當然的事物放進括號，回到意識中事物顯現的方式。 |
| 存而不論 / 懸置 (bracketing, epoché) | 中止判斷，把既有的信念、知識和假設暫時放一旁，使現象本身得以呈現。 |
| 意向性 (intentionality) | 意識總是「朝向某個對象」的特性，現象學描述的就是意識如何指向事物。 |
| 本質 (essence) | 現象中恆常不變的結構，是人類經驗共通的部分。 |
| 前置了解 (pre-understanding) | 研究者在研究前已有的先備知識與預設（海德格稱 fore-meaning）。 |
| 互為主體性 (intersubjectivity) | 研究者與參與者是平等主體，彼此了解、合作，共同建構意義。 |
| 同質性 (sameness) / 獨特性 (uniqueness) | 前者指人類經驗共通的本質，後者指個人經驗的特殊性，兩者並存。 |
| 意義的三個層次 | 事實性（字面意義）、共通性（情境中的意思，如邀請喝咖啡）、互為主體性（受社會文化系統影響的意義）。 |

### 研究方法
| 名詞 | 解釋 |
|---|---|
| 現象學描述 (phenomenological description) | 忠實、具體地描述經驗的顯現方式，不加理論詮釋，也不挖掘深層結構。 |
| 生活經驗 (lived experience) | 在日常生活中親身經歷的、尚未經過抽象化的經驗。 |
| 開放心胸 / 開放心智 | 前者指聆聽不評判、適度自我表露；後者指無目標導向、敏銳地接收訊息。 |
| 立即性 (immediacy) | 研究者與受訪者建立緊密、信任的關係，使受訪者自由表露。 |
| 共同研究者 (co-researcher) | 視參與者為一起探索與分析主題的夥伴，而非被研究的對象。 |
| 深度訪談 (in-depth interview) | 以開放性問題引導受訪者自由敘述經驗，是現象學最常用的資料蒐集方法。 |
| 逐字稿 (verbatim transcription) | 把訪談錄音一字不漏謄寫成文字，作為分析的文本。 |
| 文本 (text) | 現象學分析的資料，包括逐字稿、日誌、田野筆記、對話等書面材料。 |
| 整體–部分–整體 (whole-parts-whole) | 分析的循環架構：先整體閱讀，再拆成部分，最後回到整體，不斷往返以達到了解。 |
| 去脈絡化 (decontextualization) | 為了萃取主題，暫時把資料從原本的情境脈絡中拆出來。 |
| 意義單元 (meaning units) | 從文本中依研究問題劃分出的、具有意義的最小單位。 |
| 主題 (theme) / 共同主題 (common theme) | 從多筆資料群聚出的意義單位；共同主題是在多數或全部受訪者經驗中出現的主軸。 |
| 次主題 (sub-themes) | 共同主題之下再細分出的項目。 |
| 詮釋學循環 / Gadamer 的了解 | 了解整體要靠細節，了解細節要靠整體，來回往返直到達到和諧一致。 |
| 完形心理學 (Gestalt psychology) | 強調整體大於部分之和；本文用來比喻整體與部分的前景、背景互換。 |

### 其他
| 名詞 | 解釋 |
|---|---|
| 類化 (generalization) | 把研究發現推論到更大的母群；現象學不做這種推論。 |
| 批判教育學 (critical pedagogy) | 關注教育中的權力與不平等，並尋求改變的教育理論。 |
| 教育學的能力 (pedagogical competence) | 教育者透過專業知識與對受教者的真正了解，創造良好學習機會的能力。 |
| 深思熟慮 (thoughtfulness) | 對研究對象反思、再反思，以期整體全面考量的態度，Van Manen 用來形容現象學的特色。 |
